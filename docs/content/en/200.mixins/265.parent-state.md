---
title: parent-state
description: "Allows to set a pseudo-element rules depending on its parent state right in the rule set of the pseudo-element itself."
---

## Arguments

| Name                                        | Type   | Default | Description                                                              |
| ------------------------------------------- | ------ | ------- | ------------------------------------------------------------------------ |
| $states <span class="text-red-600">*</span> | `list` | —       | Pseudo-element parent state(s) (pseudo-classes, modifier classes, etc.). |

## Example

::code-group

  ```scss [SCSS]
  @use 'more-sass' as more;

  .element {
    &::after {
      @include more.parent-state(':hover', '.is-active') {
        color: #f00;
      }
    }
  }
  ```

  ```css [Output]
  .element:hover::after,
  .element.is-active::after {
    color: #f00;
  }
  ```

::
