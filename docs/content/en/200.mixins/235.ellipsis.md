---
title: ellipsis
description: "Truncates text of the current element and adds an ellipsis to represent overflow."
---

## Arguments

| Name             | Type     | Default | Description                    |
| ---------------- | -------- | ------- | ------------------------------ |
| $max-inline-size | `number` | 100%    | The element inline size limit. |

## Example

::code-group

  ```scss [SCSS]
  @use 'more-sass' as more;

  .element {
    @include more.ellipsis;
  }
  ```

  ```css [Output]
  .element {
    max-inline-size: 100%;
    text-overflow: ellipsis;
    white-space: nowrap;
    overflow: hidden;
  }
  ```

::
