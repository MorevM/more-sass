---
title: ellipsis
description: "Обрезает текст, выходящий за пределы текущего элемента, и добавляет в конце многоточие."
---

## Параметры

| Имя              | Тип      | По умолчанию | Описание                             |
| ---------------- | -------- | ------------ | ------------------------------------ |
| $max-inline-size | `number` | 100%         | Ограничение inline-размера элемента. |

## Пример использования

::code-group

  ```scss [SCSS]
  @use 'more-sass' as more;

  .element {
    @include more.ellipsis;
  }
  ```

  ```css [Результат]
  .element {
    max-inline-size: 100%;
    text-overflow: ellipsis;
    white-space: nowrap;
    overflow: hidden;
  }
  ```

::
