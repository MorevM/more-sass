## br-hide

Удаляет переносы строк внутри текущего элемента.

### Параметры

—

### Пример использования

::code-group

  ```scss [SCSS]
  @use 'more-sass' as more;

  .element {
    @include more.br-hide;
  }
  ```

  ```css [Результат]
  .element br {
    display: none;
  }
  ```

::

## br-show

Восстанавливает переносы строк внутри текущего элемента.

### Параметры

—

### Пример использования

::code-group

  ```scss [SCSS]
  @use 'more-sass' as more;

  .element {
    @include more.br-show;
  }
  ```

  ```css [Результат]
  .element br {
    display: block flow;
  }
  ```

::
