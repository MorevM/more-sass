Категория функций для адаптивных CSS-значений.

## use-fluid-value

Возвращает значение, равномерно масштабируемое в указанных пределах ширины экрана.

**Параметры:**

| Имя                                        | Тип    | По умолчанию | Описание                                     |
| ------------------------------------------ | ------ | ------------ | -------------------------------------------- |
| $start <span class="text-red-600">*</span> | `list` | —            | Начальная ширина экрана и значение свойства. |
| $end <span class="text-red-600">*</span>   | `list` | —            | Конечная ширина экрана и значение свойства.  |

**Возвращаемое значение:**

`?number` - Текучее выражение `clamp()`, одно фиксированное значение или `null`, если оба значения не переданы.

**Пример использования:**

```scss
@use 'more-sass' as more;

@function fluid-value($start, $end) {
  @return more.use-fluid-value((320px, $start), (1280px, $end));
}

.element {
  margin-block-start: fluid-value(16px, 32px);
}
```
